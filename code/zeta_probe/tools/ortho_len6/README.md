# ortho_len6

Exhaustive census of the **short kernel elements** of

```
rho_a : W_n  -->>  W(a) <= Isom(R^n)
```

for the right-corner orthoscheme `O(a_1,...,a_n)`, where `W_n` is the right-angled Coxeter
group on the orthogonality graph of the facets (edge whenever `|i-j| >= 2`) and `W(a)` is the
group generated by the `n+1` facet reflections.

## What it decides

Let `K(a) = min{ length(w) : w in ker rho_a, w != 1 }`, so that the collision depth is
`cd_n(a) = K(a)/2`. The paper proves `K(a) >= 6` for every positive leg tuple. The question
this tool answers, on an explicitly stated box, is whether a kernel element of length exactly
`6` can lie **outside** every rank-two standard parabolic `<R_i, R_{i+1}>`. If one could, then
`K(a) = 6` and `cd_n = 3` would be possible on the stratum `e(a) >= 1, t(a) = 0`, where the
rank-two classification only produces a relator of length `8`.

The tool is the computational side of Theorem "length six is dihedral"
(`thm:len6` in `paper/journal/paper_orthoscheme.tex`), which proves that no such element
exists for any `n >= 3` and any positive real leg tuple. The census is a falsification attempt
in the sense of Rule 3, not the proof.

Reported per box:

* violations of `K(a) >= 6` (a kernel element of length `< 6`),
* violations of the theorem (a kernel element of length `6` with support of size `>= 3`),
* the `(e,t)` class table, with the number of tuples in each class carrying a length-`6`
  kernel element, which must be exactly the classes with `t >= 1`,
* any length-`6` kernel element of support `2` that is not the alternating word
  `(R_i R_{i+1})^3`.

## Method

A kernel element of length `6` factors as `uv` with `u`, `v` reduced of length `3` and
`rho_a(u) = rho_a(v)^{-1}`; conversely two distinct elements of `W_n` of length at most `3`
with the same image produce a nontrivial kernel element of length at most `6`. So the whole
question lives in the ball of radius `3`, which has only `(n+1)(1 + n + n^2)` words. The tool
enumerates the reduced words of length at most `3`, computes their images, sorts by image,
and inspects every collision.

Reducedness and the invariants of a kernel element use the deletion condition for graph
products: a word is reduced in `W_n` iff no two positions carry the same letter with every
letter strictly between commuting with it. `reduce(u ++ reverse(v))` is empty exactly when `u`
and `v` are the same element of `W_n`, and otherwise its length and support are the invariants
of `uv^{-1}`.

## Exactness

Legs are positive integers. Every positive rational tuple scales to a primitive integer tuple,
and `rho_a(w) = 1` is invariant under scaling the legs, so integer boxes cover the rational
case. Each facet reflection is stored as an **integer** homogeneous `(n+1) x (n+1)` matrix
with bottom row `(0,...,0,D)`, representing `x |-> (Sx + b)/D`:

```
R_0 : hyperplane {x_1 = a_1},  normal e_1,                        D = 1,                b = 2 a_1 e_1
R_j : hyperplane through 0,    normal a_{j+1} e_j - a_j e_{j+1},  D = a_j^2 + a_{j+1}^2, b = 0
R_n : hyperplane {x_n = 0},    normal e_n,                        D = 1,                b = 0
```

Products are exact integer matrix products; no floating point is used anywhere. Entries are
`i128`, every multiplication and addition is `checked_*`, and the program panics rather than
wrap. Matrices are reduced by their content after each product, so equality of the affine maps
is equality of the normalised integer matrices.

## Usage

```
cargo build --release
target/release/ortho_len6 <n> <L> [--quiet]      # every primitive tuple in {1..L}^n
./sweep.sh                                       # the boxes reported in the paper
```

Run under `../runcap.sh` (Rule 8). Peak RSS is about 1 MB; the cost is CPU only.
