# atlas.txt -- the leg tuples quoted in paper/journal/paper_orthoscheme.tex, with the layer
# counts and collision depths the paper states, as expectations the tool checks.
#
# Format, fields separated by "|":
#     label | legs | depth | expected layer counts u_0..u_k | expected collision depth
# Legs are positive rationals p or p/q.  The expected collision depth is the depth of the first
# deviation from the envelope (1+t)^{n+1}/J_{n+1}(t), or "inf" for no deviation up to the depth
# run.  The last two fields are optional; when present a mismatch is a FAIL and the tool exits
# nonzero.  Every row is run at two 61-bit primes and the two runs must agree.
#
# Run:  ../runcap.sh 14000 900 target/release/ortho_cd
# The Class C depth ladder is in atlas_deep.txt and is not run from here.
