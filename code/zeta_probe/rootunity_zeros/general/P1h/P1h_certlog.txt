## Exit-code convention (Reviewer AD, 2026-09-24)
Lines 'exit N' recorded from 2026-09-24 on are the exit status of the certificate script itself: each run is
  perl -e 'alarm 290; exec @ARGV' python3 SCRIPT ARGS > FILE 2>&1; echo "exit $?" >> FILE
(no pipe, so $? is the script's status; with a pipe use ${PIPESTATUS[0]}). 'exit' lines ABOVE the 2026-09-24 reruns
(seeds, Lemma B' exact) may have been written after a '| tail' pipe and then record tail's status, not the script's; their PASSED lines are
printed only after all checks, and every failure path calls sys.exit(1) after printing FAILED, so PASSED lines are
still conclusive, but the exit codes there are not independent evidence.
P1h_caseA.py minimum interval width is now 1e-15 (was 1e-30): below it the script prints CASEA FAILED and exits 1.
The caseA_R*.txt logs above predate this change (and the Y/G/ETA fields in PASSED lines) and were NOT rerun.
