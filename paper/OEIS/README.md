# `paper/OEIS/`

The b-files for the published sequences. The submission drafts and the
paste-ready per-field blocks live in `clean/` and `submit/`, which are in
`.gitignore` and do not ship.

| File | Contents |
|---|---|
| `b396406.txt` | b-file for [A396406](https://oeis.org/A396406), `n = 0..38`. |
| `b396406_depth42.txt` | The same extended to `n = 0..42`. The last four terms `u_39..u_42` were recovered from stored double-precision logarithms rather than regenerated by the growth BFS, which is sound to `u_39`. See the provenance note at the head of `code/data/u_terms_43.txt` and the Sequence section of the top-level `README.md`. |

## Published

| Sequence | What it counts |
|---|---|
| [A396406](https://oeis.org/A396406) | 2D right triangle, unequal legs. The planar sequence, which agrees with the rational envelope `W_2(t)` only to degree 9. |
| [A397439](https://oeis.org/A397439) | 3D orthoscheme, pairwise distinct legs. |
| [A397437](https://oeis.org/A397437) | 4D orthoscheme, pairwise distinct legs. |
| [A396927](https://oeis.org/A396927) | 5D orthoscheme, pairwise distinct legs. |
| [A397438](https://oeis.org/A397438) | 6D orthoscheme, pairwise distinct legs. |

The `n = 7` entry is in preparation. Each orthoscheme entry is the coefficient
sequence of the rational function `W_n(t)` of `paper_orthoscheme.tex`, with
dominant pole `1/r_n`, `r_n = 1 + 2 cos(2 pi/(n+3))`; see `rem:oeis` there.

The 3D cube corner `(1,1,1)` was dropped as a duplicate of
[A008137](https://oeis.org/A008137), the growth series of the affine Weyl
group `B~_3`.
